# מדריך משתמש - מערכת Mini CRM

## התקנת סביבת פייתון

### דרישות מערכת
- Python 3.8 ומעלה
- Git (לגיבוי ושיתוף)
- Windows/Linux/macOS

### התקנה
```bash
# שכפול הפרויקט
git clone <repository-url>
cd mini_crm

# יצירת סביבה וירטואלית
python -m venv venv

# הפעלת הסביבה הוירטואלית
# Windows:
venv\Scripts\activate
# Linux/macOS:
source venv/bin/activate

# התקנת תלויות
pip install -r requirements.txt

# הפעלת המערכת
python app.py
```

## טעינת קבצים

### סדר טעינה מומלץ
1. **YL** - קבצי יהב לוי (בדרך כלל הקבצים הגדולים ביותר)
2. **FNX** - קבצי פניקס
3. **MOR** - קבצי מור
4. **אחרים** - קבצים נוספים לפי הצורך

### תהליך טעינה
1. היכנס לדף "העלאת קבצים" בתפריט הראשי
2. בחר את סוג המקור (YL/FNX/MOR)
3. בחר את תאריך הצילום (snapshot_date)
4. גרור את הקובץ או לחץ "בחר קובץ"
5. לחץ "העלה קובץ"
6. המתן לסיום העיבוד והצגת התוצאות

### טיפים לטעינה
- וודא שהקובץ בפורמט Excel (.xlsx)
- בדוק שהעמודות תואמות למבנה הצפוי
- טען קבצים בסדר כרונולוגי (מהישן לחדש)

## הפעלת סקריפט סגירה חודשי

### מתי להפעיל
- בתחילת כל חודש (יום 1-5)
- לאחר טעינת כל קבצי החודש החדש
- לפני הפקת דוחות חודשיים

### הפעלה רגילה
```bash
# הפעלה עם הגדרות ברירת מחדל (2 חודשים)
python tools/mark_closed_funds.py

# הפעלה עם פרמטר מותאם אישית
python tools/mark_closed_funds.py --months 3
```

### הפעלה במצב ניסיון (Dry-Run)
```bash
# בדיקה מה יקרה ללא ביצוע שינויים
python tools/mark_closed_funds.py --dry-run

# בדיקה עם פרמטר מותאם אישית
python tools/mark_closed_funds.py --dry-run --months 3
```

### פרשנות תוצאות
- **Active funds**: מספר קופות פעילות
- **Inactive funds**: מספר קופות שנסגרו
- **Funds marked as closed**: מספר קופות שנסגרו בהפעלה הנוכחית

## הורדת דוח CSV דרך הדאשבורד

### גישה לדוחות
1. היכנס לדף הבית (Dashboard)
2. גלול למטה לקטע "דוחות"
3. בחר את סוג הדוח הרצוי:
   - **סיכום לקוחות** - רשימת כל הלקוחות עם סיכום קופות
   - **פירוט קופות** - רשימה מפורטת של כל הקופות הפעילות
   - **היסטוריית שינויים** - מעקב אחר שינויים בזמן

### הורדת דוח
1. לחץ על כפתור "הורד CSV" ליד הדוח הרצוי
2. הקובץ יורד אוטומטית לתיקיית ההורדות
3. פתח בExcel או בתוכנת גיליונות אלקטרוניים אחרת

### עיבוד נתונים
- הקבצים מכילים כותרות בעברית
- התאריכים בפורמט ISO (YYYY-MM-DD)
- הסכומים במטבע המקומי (ללא עיצוב)

## עריכת לקוח במודאל

### פתיחת חלון עריכה
1. היכנס לדף פרטי הלקוח
2. לחץ על לשונית "פרטי לקוח"
3. לחץ על כפתור "ערוך פרטי לקוח"

### שדות הניתנים לעריכה
- **שם פרטי ומשפחה**
- **טלפון ואימייל**
- **כתובת**: רחוב, מספר בית, עיר

### שמירת שינויים
1. ערוך את השדות הרצויים
2. לחץ "שמור שינויים"
3. המתן להודעת אישור
4. הדף יתרענן אוטומטית עם הנתונים החדשים

### טיפול בשגיאות
- אם השמירה נכשלה, תופיע הודעת שגיאה
- בדוק את החיבור לאינטרנט
- וודא שהשדות מכילים נתונים תקינים

## גיבוי Git + pre-commit

### הגדרת Git
```bash
# הגדרת פרטי משתמש (חד-פעמי)
git config --global user.name "השם שלך"
git config --global user.email "your.email@example.com"

# יצירת repository חדש (אם צריך)
git init
git remote add origin <repository-url>
```

### גיבוי יומי
```bash
# הוספת כל השינויים
git add .

# יצירת commit עם הודעה תיאורית
git commit -m "עדכון נתונים - $(date +%Y-%m-%d)"

# העלאה לשרת
git push origin main
```

### התקנת pre-commit hooks
```bash
# התקנת pre-commit
pip install pre-commit

# הגדרת hooks
pre-commit install

# הפעלה ידנית על כל הקבצים
pre-commit run --all-files
```

### קובץ .pre-commit-config.yaml
```yaml
repos:
  - repo: https://github.com/psf/black
    rev: 22.3.0
    hooks:
      - id: black
        language_version: python3
  - repo: https://github.com/pycqa/flake8
    rev: 4.0.1
    hooks:
      - id: flake8
  - repo: https://github.com/pre-commit/pre-commit-hooks
    rev: v4.2.0
    hooks:
      - id: trailing-whitespace
      - id: end-of-file-fixer
      - id: check-yaml
```

## פתרון בעיות נפוצות

### המערכת לא עולה
1. בדוק שהסביבה הוירטואלית פעילה
2. וודא שכל התלויות מותקנות: `pip install -r requirements.txt`
3. בדוק שקובץ הDB קיים: `crm.db`

### שגיאות בטעינת קבצים
1. וודא שהקובץ בפורמט נכון (.xlsx)
2. בדוק שהעמודות תואמות למבנה הצפוי
3. נסה לפתוח את הקובץ בExcel ולשמור מחדש

### בעיות בעדכון לקוחות
1. רענן את הדף ונסה שוב
2. בדוק שהחיבור לאינטרנט יציב
3. וודא שהנתונים תקינים (אימייל, טלפון)

### גיבוי לא עובד
1. בדוק שGit מותקן ומוגדר
2. וודא שיש חיבור לrepository המרוחק
3. נסה: `git status` לבדיקת מצב הrepository
