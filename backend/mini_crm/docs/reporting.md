# מדריך דוחות לקוח - Mini CRM

## סקירה כללית

מערכת הדוחות מאפשרת הפקת דוחות מותאמים אישית לכל לקוח בפורמטים שונים:
- **CSV** - לעיבוד נתונים וייבוא למערכות אחרות
- **Excel** - כולל דפי סיכום ופיבוטים
- **PDF** - דוח מעוצב להדפסה ושליחה ללקוחות

## איך להוריד דוח לקוח

### דרך הממשק (UI)

1. **היכנס לדף פרטי הלקוח**
   - מהדשבורד הראשי, לחץ על שם הלקוח
   - או השתמש בחיפוש לקוח

2. **בחר את לשונית "פרטי לקוח"**

3. **לחץ על כפתור "הורד דוח"**
   - יפתח תפריט נפתח עם 3 אפשרויות
   - בחר את הפורמט הרצוי: CSV / Excel / PDF

4. **בחר חודש (אופציונלי)**
   - השתמש בבורר התאריך "בחר חודש לדוח"
   - אם לא תבחר חודש, תקבל את הנתונים מהחודש האחרון
   - פורמט: YYYY-MM (לדוגמה: 2025-07)

5. **הקובץ יורד אוטומטית**
   - הקובץ יישמר בתיקיית ההורדות שלך
   - שם הקובץ יכלול את שם הלקוח והתאריך

### דרך API (curl)

```bash
# דוח CSV לחודש האחרון
curl -o client_report.csv "http://localhost:5000/report/client/123.csv"

# דוח Excel לחודש ספציפי
curl -o client_report.xlsx "http://localhost:5000/report/client/123.xlsx?month=2025-07"

# דוח PDF
curl -o client_report.pdf "http://localhost:5000/report/client/123.pdf?month=2025-07"
```

**פרמטרים:**
- `client_id` - מזהה הלקוח במערכת
- `fmt` - פורמט הקובץ (csv/xlsx/pdf)
- `month` - חודש בפורמט YYYY-MM (אופציונלי)

## פורמט הדוחות

### עמודות בדוח

| עמודה | תיאור | דוגמה |
|--------|--------|--------|
| שם פרטי | השם הפרטי של הלקוח | יוסי |
| שם משפחה | שם המשפחה של הלקוח | כהן |
| ת"ז | מספר תעודת הזהות | 123456789 |
| מס' קופה | מספר הקופה/פוליסה | FUND001 |
| שם קופה | השם המלא של הקופה | קופת גמל כללית |
| סוג מוצר | סוג המוצר הפנסיוני | קופת גמל |
| חברה | שם החברה המנהלת | פניקס |
| מקור | קוד המקור במערכת | FNX |
| יתרה | יתרת הקופה בשקלים | 50,000.00 |
| תאריך צילום | תאריך הנתונים | 2025-07-01 |

### דוח Excel - דפים נוספים

**דף "סיכום":**
- סך כל היתרות
- מספר קופות
- תאריך הפקת הדוח

**דף "לפי סוג מוצר":**
- פיבוט של היתרות לפי סוג מוצר
- אחוזים מסך הכל

**דף "לפי חברה":**
- פיבוט של היתרות לפי חברה מנהלת
- אחוזים מסך הכל

### דוח PDF - תכולה

**כותרת:**
- לוגו החברה (אם קיים)
- כותרת הדוח
- תאריך הפקה

**פרטי הלקוח:**
- שם מלא, ת"ז, טלפון, אימייל
- חודש הדוח (אם נבחר)

**סיכום:**
- סך כל היתרות
- מספר קופות

**טבלת קופות:**
- כל הקופות הפעילות
- ממוינות לפי גובה היתרה

**פיבוטים:**
- פילוח לפי סוג מוצר (עם אחוזים)
- פילוח לפי חברה (עם אחוזים)

## איך לשנות לוגו ב-PDF

1. **הכן קובץ לוגו**
   - פורמט: PNG או JPG
   - רזולוציה מומלצת: 300x150 פיקסלים
   - גודל מקסימלי: 500KB

2. **העתק את הקובץ**
   ```bash
   cp your_logo.png static/logo.png
   ```

3. **אתחל את המערכת**
   ```bash
   # עצור את המערכת
   Ctrl+C
   
   # הפעל מחדש
   python app.py
   ```

4. **בדוק את התוצאה**
   - הפק דוח PDF חדש
   - הלוגו יופיע בכותרת הדוח

## התקנת תלויות ל-PDF

### Windows

1. **הורד wkhtmltopdf**
   ```bash
   # הורד מ: https://wkhtmltopdf.org/downloads.html
   # התקן את הקובץ .exe
   ```

2. **התקן pdfkit**
   ```bash
   pip install pdfkit
   ```

3. **הגדר PATH (אם נדרש)**
   ```bash
   # הוסף לPATH את התיקייה:
   # C:\Program Files\wkhtmltopdf\bin
   ```

### Linux (Ubuntu/Debian)

```bash
# התקן wkhtmltopdf
sudo apt-get update
sudo apt-get install wkhtmltopdf

# התקן pdfkit
pip install pdfkit
```

### macOS

```bash
# התקן wkhtmltopdf
brew install wkhtmltopdf

# התקן pdfkit
pip install pdfkit
```

## פתרון בעיות נפוצות

### שגיאה: "PDF generation not available"

**גורם:** pdfkit או wkhtmltopdf לא מותקנים

**פתרון:**
1. התקן את wkhtmltopdf לפי המערכת שלך
2. התקן pdfkit: `pip install pdfkit`
3. אתחל את המערכת

### שגיאה: "No data found for this client"

**גורמים אפשריים:**
- מזהה לקוח שגוי
- אין נתונים פעילים ללקוח
- החודש שנבחר לא קיים

**פתרון:**
1. בדוק שמזהה הלקוח נכון
2. ודא שיש נתונים פעילים ללקוח בדשבורד
3. נסה ללא פרמטר חודש (לקבלת הנתונים האחרונים)

### שגיאה: "Invalid month format"

**גורם:** פורמט חודש שגוי

**פתרון:** השתמש בפורמט YYYY-MM (לדוגמה: 2025-07)

### הדוח ריק או חסרים נתונים

**גורמים אפשריים:**
- הקופות מסומנות כלא פעילות
- הנתונים מחודש ישן מדי

**פתרון:**
1. בדוק בדשבורד שהקופות מסומנות כפעילות
2. הרץ את סקריפט עדכון הקופות:
   ```bash
   python tools/mark_closed_funds.py --dry-run
   ```
3. אם הקופות נסגרו בטעות, עדכן ידנית:
   ```sql
   UPDATE snapshot SET is_active = 1 
   WHERE client_id = ? AND fund_number = ?;
   ```

### דוח PDF לא מעוצב כראוי

**גורמים אפשריים:**
- בעיות עם גופנים עבריים
- בעיות עם RTL

**פתרון:**
1. ודא שהגופן Heebo זמין
2. בדוק את הגדרות wkhtmltopdf:
   ```bash
   wkhtmltopdf --version
   ```

### ביצועים איטיים בדוחות גדולים

**אופטימיזציות:**
1. השתמש בפילטר חודש ספציפי
2. בדוק שהאינדקסים בDB תקינים:
   ```sql
   CREATE INDEX IF NOT EXISTS idx_snapshot_client_date 
   ON snapshot(client_id, snapshot_date);
   ```

## אבטחה ופרטיות

### הגנת נתונים
- כל הדוחות מכילים מידע רגיש
- ודא שהקבצים נשמרים במקום מאובטח

- כל הורדה נרשמת בלוגים
- ניתן להגביל גישה לפי תפקיד (עתידי)

### גיבוי ושחזור
```bash
# גיבוי DB לפני הפקת דוחות מסיביים
cp crm.db crm_backup_$(date +%Y%m%d).db

# בדיקת תקינות הנתונים
sqlite3 crm.db "SELECT COUNT(*) FROM snapshot WHERE is_active=1;"
```

## מעקב ומוניטורינג

### לוגים
- דוחות נרשמים ב: `logs/app.log`
- שגיאות PDF נרשמות בפירוט
- זמני תגובה נמדדים

### סטטיסטיקות שימוש
```sql
-- דוחות שהופקו היום
SELECT COUNT(*) FROM access_log 
WHERE date = date('now') AND endpoint LIKE '/report/client%';

-- הלקוחות הפופולריים ביותר לדוחות
SELECT client_id, COUNT(*) as report_count
FROM access_log 
WHERE endpoint LIKE '/report/client%'
GROUP BY client_id 
ORDER BY report_count DESC 
LIMIT 10;
```
